# 비용 화면 개선 설계

대상: skifighting-afk/plus-ev, plusevapp.kr

## 선택한 방식
기존 비용 카드에 상세 내역·전체 수정·항목 설정을 통합한다. 별도 비용 관리 페이지는 이동이 늘어나므로 이번에는 만들지 않는다. 사용자가 기존 화면 확장을 선택했다.

## 화면과 동작
- 비용 카테고리를 누르면 선택한 월의 날짜·금액·메모·영수증 내역과 합계를 보여준다. 쿠팡 등 사용자 항목도 동일하게 동작한다.
- ‘전체 수정’에서 여러 지출의 날짜·항목·금액·메모를 편집하고 한 번에 저장한다. 변경한 행만 저장하며 실패한 항목을 명확하게 보여준다. 마감과 연결된 지출의 날짜·금액은 기존처럼 마감 화면에서 수정한다.
- ‘항목 설정’에서 사용자 카테고리 추가, 표시 이름 변경, 순서 변경, 숨김 및 0원 항목 표시 여부를 설정한다. 표시 이름은 거래의 식별자와 분리한다. 숨겨도 기존 거래와 합계는 보존한다.
- 설정은 기존 매장 설정에 저장하며 같은 매장의 화면에 반영한다. 수정 권한은 기존 매장 역할과 서버 권한을 유지한다.
- 월 고정비 편집은 기존 기능을 유지한다. 직접 입력한 지출과 고정비 추정액을 구분해 보여준다.

## 금액 기준
현재 코드는 순이익 상세에서 오늘까지의 지출과 일할 고정비를, 비용 카드에서 월 전체 지출과 월 고정비를 사용한다. 이것만으로 사진의 금액 오류 원인이 확정되지는 않았다.

월 전체 비용과 오늘까지 반영 비용을 명확히 표시한다. 같은 기간·같은 기준의 카드 합계와 상세 합계를 일치시킨다. 고정비와 실제 지출의 중복 반영, 미래 날짜 지출, 카드 수수료 추정값을 검증한다. 사진 속 실제 거래 금액을 임의로 변경하지 않는다.

## 검증과 결과
기존 비용 합계·수정 테스트 두 개는 통과했다. 이후 카테고리별 합계, 월 경계, 일괄 수정 실패, 마감 연결 지출 보호, 설정 저장과 합계 보존을 검증한다. 변경 결과는 별도 브랜치와 검토 가능한 변경본으로 준비하며 실제 배포 여부를 따로 명시한다.

0. 시작 전 체크 5분

1. 설치·가입 처음 한 번

1
앱 열기 📍 폰·PC 브라우저
  • 주소창에 plusevapp.kr 입력
  • 안드로이드: Chrome 메뉴 ⋮ → 홈 화면에 추가 · 아이폰: 공유 → 홈 화면에 추가
  • 플레이 스토어 출시 후엔 +EV 검색해 설치해도 돼요
홈 화면에 +EV 아이콘이 생겨요. 앱처럼 열려요.
2
가입 📍 첫 화면
  • 처음이에요 (가입) → 이름·이메일·비밀번호(6자 이상) → 가입하기
  • "어떤 분이세요?" → 대표·점장 및 매장이에요
점장은 여기서 가입하지 않아요. 직원으로 가입 → 대표가 점장 권한을 주면 돼요 (5단계).
3
매장 등록 📍 매장 등록 화면
  • 회사(상호) · 브랜드(프랜차이즈면) · 사업자등록번호 10자리 · 첫 매장 이름 · 지역 · 대표님 이름
  • 매장 만들기
한 달(30일) 무료 체험 시작. 홈(브리핑)이 열려요. 체험이 끝나도 데이터는 그대로 남아요.

2. 매장 세팅 첫날 20분

4
매장 정보 📍 오른쪽 위 ⚙ 매장 설정
  • 매장 정보: 주소(구인 공고에 지도로 나가요) · 평수 · 테이블 수 · 야간 시작/끝 → 저장
  • 매장이 더 있으면 "매장 추가" → 매장 추가 (무료, 요금은 회사당 하나)
평수·테이블 수를 넣어야 나중에 "주변 매장과 비교"가 정확해요.
5
직원 등록 📍 아래 탭 직원 › 직원·급여
  • + 직원 등록
  • 닉네임 · 실명 · 직책(딜러/플로어/매니저) · 계약(3.3% / 4대보험) · 시급 · 입사일 · 연락처
  • 고용 형태(정규/파트타임/대타) · 야간수당 · 연장·주휴수당 · 은행·계좌·예금주
  • 저장 — 직원 수만큼 반복
급여가 자동으로 계산되기 시작해요. 퇴사는 수정 → 퇴사 처리.
5+
근로계약서 보내기 📍 직원 탭 › "표준 근로계약서" 띠 · 직원 카드
  • 처음 한 번: 표준 양식 관리 → 근무 요일·시간·지급일 → 양식 저장
  • 직원 카드 "근로계약서" 보내기 → 확인 → 패드에 서명 → 대표 서명하고 보내기
  • 여러 명이면 미발송 N명 한 번에 보내기 · 앱 없는 직원은 링크 복사·카톡·문자로 보내기
직원이 폰에서 서명하면 체결 완료. 보기·출력으로 인쇄·PDF.
6
직원 앱 연결 (가입코드) 📍 직원 탭 맨 아래 "매장 가입코드"
  • 복사 → 직원에게 카톡으로 보내기 (D-로 시작하는 코드)
  • 직원이 앱에서 소속 신청하면 홈·직원 탭에 "소속 신청"이 떠요 → 승인
  • "새 직원으로 등록" 또는 "이미 등록된 ○○와 연결" 고르기 → 승인하기
  • 점장 줄 사람: 직원 카드의 점장 권한
직원 카드에 앱 연결 표시. 그 직원은 자기 폰으로 출퇴근·근무표·급여를 봐요.
7
고정비 📍 홈 › "N월 고정비" 카드
  • N월 수정 → 임대료 · 관리비 · 전기세 · 수도세 · 통신·보안 → 저장
  • 연간 보기에서 월별 확인
한 번 넣으면 다음 달부터 자동으로 이어져요. 바뀐 달만 다시 수정.
8
적정 인원 + 매주 기본 근무 📍 아래 탭 스케줄
  • 맨 위 "적정 인원": 요일별·공휴일 숫자 입력 (예: 금 6, 토 7)
  • 매주 기본 → 직원 × 요일 칸의 + → 시작·끝·휴게 → 저장
  • 날짜별로 다르면 월간에서 그날만 고치기: 이름 누르고 끌기 · Ctrl+C/V · Delete=휴무
  • 하루 자세히: 일간 → + 근무 추가 · 공휴일로 지정
달력에 3/4처럼 "근무/적정"이 보여요. 빨간 날 = 사람이 모자란 날.
9
이번 달 목표 매출 📍 홈 › "N월 목표 매출" 카드
  • 이걸로 정하기(추천값) 또는 직접 정하기
홈에 달성률·오늘 할 일이 매일 새로 떠요. 마감이 쌓이면 추천값이 생겨요.

자주 묻는 것

직원이 여러 매장을 오가요

매장마다 가입코드로 소속 신청하면 돼요. 직원 앱에서 매장을 골라 봐요.

마감을 며칠 빼먹었어요

매출 탭 마감 칸의 날짜를 바꿔서 하루씩 넣으세요. 손익은 다시 계산돼요.

체험(한 달)이 끝나면 데이터가 지워지나요?

아니요. 보기만 되고 입력이 막혀요. 요금제를 고르면 바로 이어서 쓸 수 있어요.

점장이 못 하는 것

매장 정보 수정 · 요금제 결제 · 점장 권한 주기 · 매장 추가는 대표만 돼요. 점장은 스케줄·매출·구인·직원 등록을 해요.

포스기 연동

매출 탭 맨 위 포스기 연동하기 → 포스 종류 선택 → 준비되면 알림. 연동 전엔 숫자를 직접 넣어요.
